# Black Violet

Почти чёрная тема с фиолетовыми акцентами для KDE Plasma и Kvantum.

[Скачать BlackViolet.zip](./BlackViolet.zip)

Распакуйте архив, откройте терминал в папке `BlackViolet` и запустите:

```bash
bash apply.sh
```

Запускайте в своём сеансе KDE без sudo. Скрипт создаёт резервную копию настроек KDE и Kvantum и выводит команду отката. Затем выйдите из сеанса и войдите снова.

Если панель остаётся серой, выберите стиль Plasma **Breeze** вместо **Breeze Dark**. Это отдельное ручное изменение; вернуть его можно выбором Breeze Dark.

Терминалы, браузер, GTK-приложения и экран входа автоматически не изменяются.

Проверены XML SVG, значения цветов и синтаксис shell-скриптов. Визуальная проверка в KDE ещё требуется.

Основано на предоставленных файлах KvSimplicityDark (Tsu Jan) и схеме 1337. Подробности и ограничения отката — в README.txt внутри архива.
